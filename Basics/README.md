# 📘 Basics

## Topic Gist

The foundation of the DSA journey — everything here is **loop mechanics, math tricks, recursion fundamentals and hashing** before any advanced data structure appears. This folder groups the beginner modules: pattern printing, core maths, arrays, strings, hashing, recursion and a Java Collections reference track.

## 🧭 General Approach

- **Learn the pattern once, reuse it everywhere** — nested loops (Patterns), digit loops (`%10`/`/10`), frequency counting (Hashing), base-case-first thinking (Recursion).
- Where a file exists in both brute-force and optimized form (`DuplicateB`/`DuplicateO`, `Square_of_SortedArray`/`_OP`), read them in that order — the complexity jump is the lesson.
- Each `.java` file opens with a `//TODO:` problem statement plus **Time/Space complexity** comments; every folder README carries the linked index and theory notes.

*See each subfolder's README for its own index and notes.*
